# Password Security Analyzer

## Project Overview

Password Security Analyzer is a Java console-based application that checks the strength of a password using different security rules.

The application analyzes password length, uppercase letters, lowercase letters, numbers, special characters, and common password patterns.

It also calculates a security score and provides suggestions for creating stronger passwords.

## Features

- Password strength analysis
- Security score from 0 to 100
- Uppercase character checking
- Lowercase character checking
- Number checking
- Special character checking
- Common password detection
- Security suggestions
- Simple console-based interface
